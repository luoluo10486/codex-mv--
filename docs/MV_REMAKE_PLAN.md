# 《勾指起誓》完整版 MV 重制计划

执行状态：阶段 0–6 已完成。48/48 镜头已合并，正式完整版、30 秒预览与最终低清完整版已验证。最终产物及验收边界见 `docs/MV_FINAL_REPORT.md`，逐阶段证据见 `docs/MV_STAGE_LOG.md`。

## 固定目标

- 输出规格：1920×1080、30fps、5508 帧，保留原曲音频。
- 镜头规模：40 个歌词主镜头 + 8 个间奏/转场镜头。
- 风格：暖色梦幻插画；不使用手绘线稿。
- 主色：奶油、杏橙、珊瑚、暖红、琥珀金、酒红、深棕紫。
- 叙事硬要求：圣诞老人、雪橇、雪夜、礼物、铃铛、月色、三千世界、金色契约、牵手和远行必须在对应歌词时间出现。

## 分幕

1. **信、童话和圣诞礼物**：信封、诗页、童话书、月色、圣诞老人、雪橇和礼物。
2. **三千世界和关系靠近**：水瓢、水滴世界、靠近、温暖、坚强、柔软、契约、岁月、牵手和远行。
3. **万水千山和人生之线**：山海、标记塔、人生之线、前世回眸、世界之心。
4. **闪亮、平凡、柔软和敏感**：星光扩散、平凡人物、花园、玻璃水滴、第二次契约。
5. **回归和最终远行**：回到暖色房间，四季、牵手、远行，信件化为星星。

## 多代理边界

- 根代理独占：`src/Root.tsx`、`src/dream/DreamFullMv.tsx`、`src/dream/DreamMv.tsx`、`src/data/full-timeline.json`、总状态、总日志和最终配置。

`docs/MV_PROGRESS.json` 是机器状态源，`docs/MV_STAGE_LOG.md` 是人工阶段记录。根代理重启时先读取这两个文件、Git 分支和已有输出；已提交且验证的场景不重做，未提交场景从最后一个稳定状态重新开始。正式视频先写入 `.partial.mp4`，验证通过后才替换正式文件。
